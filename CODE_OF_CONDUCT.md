# CoStar Code of Conduct

CoStar is for people who want to build useful context systems together.

We expect everyone in the project to be respectful, patient, and helpful.

## Our standards

Please:

- be kind and constructive
- give feedback on the work, not the person
- keep discussions focused on product, code, and user value
- assume good intent unless there is clear evidence otherwise
- respect privacy and keep real user data private

Please do not:

- harass, threaten, or insult other contributors
- share private data without permission
- use the repo to embarrass or target someone
- turn review threads into personal arguments

## If something goes wrong

If you see behavior that feels unsafe or disrespectful, contact the maintainers
privately through the repository channels or open a private GitHub issue.

We will review the report and respond as quickly as we can.
