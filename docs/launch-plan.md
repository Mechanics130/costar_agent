# CoStar Launch Plan by Codex

## Phase 1 - Builder release

Audience:

- engineers
- product builders
- self-hosting users

Message:

- CoStar is an open-core skill engine for durable relationship context.
- It helps you turn raw material into confirmed people profiles, briefs, and graphs.

Channels:

- GitHub README
- GitHub release post
- Hacker News / Product Hunt
- X / Twitter
- Reddit communities for self-hosting and local LLMs

## Phase 2 - Public proof

Assets to prepare:

- a short demo gif of capture -> briefing
- an architecture diagram
- a comparison note against Dex / Clay / Notion / ChatGPT direct usage
- a one-page pitch in English and Chinese

## Phase 3 - Consumer shell handoff

Audience:

- sales BD
- managers
- founders

Message:

- the hosted product built on top of CoStar gives you the CoS-style experience
- you do not need to see the engine details to get the value

## Current priority

The public repo should now support the builder release cleanly.
The consumer product can be promoted separately once the UI shell is ready.
